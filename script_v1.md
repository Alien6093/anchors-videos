# anchors x Zeko AI: "Gut Decisions, Meet Evidence" (v1, 60s, 16:9, no VO)

## 1. Concept, tone, arc
A silent, rhythmic product film. The campaign is the hero, and the entire LinkedIn creator campaign lives in one Claude chat. Big kinetic type sets the myth ("Structured interviews still hide gut decisions") and the chat UI busts it: one sentence typed, eight HR voices matched, drafts reviewed, three sent back, all approved, dates set, live, measured. Tone: confident, dry, precise, like a great Stripe or Linear film. Type snaps on beat, UI is the star, and every click has a sound. **Emotional arc:** Doubt (a myth, a blank chat) -> Momentum (creators appear) -> Control (you steer drafts) -> Release (Approve, Set live date, the chime peaks) -> Proof (2.8L people reached).

Look: claude.ai dark theme (#262624-ish bg), cream widgets, Claude-orange accent only on cursor/approve. Text cards: white, heavy grotesk, max 8 words. Brand always "anchors".
