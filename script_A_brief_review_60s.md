## 1. Concept, tone, arc

Same silent, exact, confident register as v4: claude.ai dark chat, serif Claude replies, grey collapsed tool lines, cream "anchors / CLEO" widgets. Orange is reserved for actions and final moments (Approve, Set live date, pay, Campaign activated); selections use a neutral cream highlight.
